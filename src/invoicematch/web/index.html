        Using InvoiceMatch

        What can I upload?
        One digitally generated INR invoice, up to 2 MiB and eight pages. Use a PDF with selectable text. Scans or unfamiliar layouts may require manual review.
        What happens to my invoice?
        The server checks custom invoices using local rules. Access to extracted fields, evidence excerpts, and decisions expires after 24 hours. You can clear the session early.
        How can I try the AI?
        Open Sample options and select Live AI. Live AI is available for the bundled samples when the server is configured for it.
